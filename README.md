# f(x) 아레나 — 함수 무기 스틱맨 액션

수학 함수를 무기에 장착하면 **그 함수의 그래프 모양 그대로** 공격이 뻗어 나가는 2D 횡스크롤 웨이브 액션 게임입니다.
TypeScript + Vite + HTML5 Canvas로 만들었고, 외부 이미지 없이 캐릭터·배경·이펙트를 모두 코드로 그립니다.

## 실행

```bash
npm install
npm run dev           # http://localhost:5173 에서 플레이
npm run build         # 타입 검사 + dist/ 빌드
npm run preview       # 빌드 결과 실행
npm run build:single  # 파일 하나짜리 게임 dist/fx-arena.html (내려받아 더블클릭으로 실행)
```

`build:single`은 JS·CSS를 HTML 안에 넣은 단일 파일을 만듭니다. 브라우저는 `file://`로 연 페이지에서
외부 모듈 스크립트를 막기 때문에, 서버 없이 파일만 공유·실행하려면 이 파일을 쓰세요.

## 조작

| 입력 | 동작 |
| --- | --- |
| `A` / `D` | 좌우 이동 |
| `W` | 점프(일찍 떼면 낮게) |
| `S` | 누르는 동안 숙이기 — 피격 높이가 실제로 낮아지고, 머리 위가 막혀 있으면 일어설 수 없음 |
| 마우스 이동 | 조준(이동 방향과 독립, 팔과 무기가 커서를 향함) |
| 좌클릭 | 한 번 클릭 = 한 번 공격, 누르고 있으면 무기 대기시간마다 연사 |
| `1`~`5` / 휠 | 장착 함수 교체 |
| `Esc` | 일시 정지 / 재개 |

## 함수 무기 5종

| 슬롯 | 함수 | 정의역 | 공격 모양 | 특징 |
| --- | --- | --- | --- | --- |
| 1 | 일차함수 `y = x` | [0, 1] | 조준선 위의 직선 | 빠른 연사(0.17s), 최장 사거리, 가장 좁은 판정 |
| 2 | 이차함수 `y = x²` | [0, 1] | 조준축에 접해 출발해 한쪽으로 휘는 포물선 | 높은 피해, 느린 발사, 넓은 높이 범위 |
| 3 | 사인함수 `y = sin(x)` | [0, 4π] | 조준축을 중심으로 2회 진동 | 여러 높이의 적을 한 번에 |
| 4 | 절댓값함수 `y = \|x\|` | [−0.5, 1] | 꼭짓점이 1/3 지점에 있는 V자 | 가장 두꺼운 판정, 강한 넉백(근접 공격 준비 끊기), 긴 대기시간 |
| 5 | 지수함수 `y = eˣ − 1` | [0, 4] | 완만하게 가다 끝에서 급격히 솟음 | 짧은 사거리, 최고 피해, 발판 위 적을 '감아 올려' 타격 |

곡선은 적을 관통하지만 한 번의 발사로 같은 적을 두 번 때리지 않습니다. 한 발로 여러 명을 처치하면 관통 보너스 점수가 붙고, 곡선은 적 탄환도 지웁니다.

## 함수 공격의 구현 방식

1. 정규화 매개변수 `t ∈ [0, 1]`로 정의역을 훑어 로컬 곡선을 만듭니다.
   `lx = L·t`, `ly = A·g(t)`, `g(t) = (f(x(t)) − f(x₀)) / max|f − f(x₀)|`
   (시작점을 원점=총구로 평행 이동, `L`=사거리, `A`=조준축에서 벗어나는 최대 높이)
2. 총구→커서 방향을 로컬 x축, 그에 수직인 방향을 로컬 +y(수학적 위)로 삼아 월드 좌표로 회전·이동합니다.
   화면 좌표는 y가 아래로 커지므로 오른쪽 조준 시 +y = 화면 위쪽이 되도록 변환합니다.
   왼쪽을 조준하면 캐릭터가 뒤돌아보듯 그래프를 좌우 반전합니다(`COMBAT.mirrorWhenAimingLeft`, `false`면 순수 회전).
3. 곡선 길이 기준 4px 간격으로 다시 나눈 선분마다 지형과의 교차를 검사해 **처음 닿은 지점에서 자릅니다.**
4. 발사 순간의 경로를 저장하고, 머리가 진행 속도만큼 앞부분부터 드러납니다 → 잠시 유지 → 꼬리부터 걷히며 사라짐 → 판정 없는 희미한 잔상.
5. 매 스텝 **현재 보이는 구간 [꼬리, 머리]의 모든 선분**과 적 피격 상자 사이의 정확한 거리를 곡선 두께(반경)와 비교하므로, 한 스텝에 머리가 멀리 나아가도 판정이 누락되지 않습니다.
6. 조준 미리보기(점선)와 실제 발사는 같은 함수 `computeAttackPath()`를 호출합니다.

## 프로젝트 구조

```
src/
  config.ts              모든 밸런스 수치(물리, 플레이어, 무기, 적, 웨이브, 이펙트)
  main.ts                진입점
  debug.ts               ?debug 로 열었을 때만 노출되는 검사용 API(window.__fx)
  core/                  기하 계산, 입력, 고정 타임스텝 루프, 뷰(레터박스·좌표 변환), 시드 난수
  world/                 아레나 지형, AABB 물리, 적 내비게이션 그래프
  weapons/               함수 무기 정의·등록, 곡선 생성/회전/지형 절단, 공격 객체
  entities/              플레이어, 적, 탄환, 파티클
  game/                  게임 상태 머신, 플레이어 조작, 무기 발사, 충돌·피해, 적 AI, 웨이브
  render/                배경·지형·스틱맨·곡선 이펙트·HUD 그리기
  ui/overlays.ts         시작/일시 정지/게임 오버 화면(DOM)
tests/                   Vitest 단위·시뮬레이션 테스트
scripts/e2e.mjs          Playwright 브라우저 E2E 검증
scripts/build-single.mjs 단일 HTML 파일 빌드
```

## 새 함수 무기 추가하기

1. `src/config.ts`의 `WEAPON_TUNING`에 수치를 추가합니다.
2. `src/weapons/functions.ts`에서 등록합니다(등록 순서 = 슬롯 번호, 숫자 키는 9번까지).

```ts
registerWeapon({
  id: 'cubic',
  name: '삼차함수',
  shape: 'S자',
  formula: 'y = x³',
  role: '…',
  color: '#4dffd2',
  domain: [-1, 1],
  fn: (x) => x ** 3,
  tuning: WEAPON_TUNING.cubic,
});
```

미리보기·발사·충돌·HUD 슬롯과 아이콘은 자동으로 따라옵니다.

## 밸런스 조정

피해량, 진행 속도, 유지/사라짐 시간, 사거리(`range`), 곡률/높이(`amplitude`), 재사용 대기시간, 판정 두께, 넉백은 모두 `src/config.ts`의 `WEAPON_TUNING` 한곳에서 바꿉니다. 적 능력치와 웨이브 증가 곡선도 같은 파일의 `ENEMIES`, `WAVES`에 있습니다.

## 테스트

```bash
npm test             # 단위·시뮬레이션 테스트(Vitest)
npm run test:e2e     # 실제 브라우저에서 키보드·마우스 입력으로 검증(Playwright)
```

E2E를 처음 실행할 때 브라우저가 없다면 `npx playwright install chromium`을 먼저 실행하세요.
이미 설치된 Chromium을 쓰려면 `CHROMIUM_PATH=/경로/chrome npm run test:e2e`.
단일 파일 빌드를 검사하려면 `npm run build:single && E2E_URL=file://$PWD/dist/fx-arena.html node scripts/e2e.mjs`.

- 단위 테스트: 5종 곡선 모양(직선/접선 출발 포물선/2회 진동/V 꼭짓점/지수 급상승), 360° 회전, 좌우 반전, 지형 절단,
  미리보기=발사 경로, 관통·중복 피해 방지·두께 경계·큰 스텝 누락 방지, 프레임 속도 독립성, 점프·숙이기·턱 아래 일어서기 불가,
  내비게이션 연결성, 근접/원거리 AI, 스폰 제약, 웨이브 증가, 그리고 봇이 2분간 실제 시스템 전체를 플레이하는 소크 테스트.
- E2E: 이동·점프·숙이기, 이동과 독립적인 조준, 5종×8방향 미리보기=실제 경로, 지형 충돌, 함수 교체(숫자/휠),
  단발/연사 간격, 실제 클릭으로 적 처치, 적 AI, 일시 정지·포커스 손실 시 입력 초기화, 웨이브, 게임 오버·재시작,
  여러 창 크기와 DPR 2에서의 조준 정확도, 콘솔 오류.
