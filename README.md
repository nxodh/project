# f(x) 아레나 — 함수 무기 스틱맨 액션

수학 함수를 무기에 장착하면 **그 함수의 그래프 모양 그대로** 공격이 뻗어 나가는 2D 횡스크롤 웨이브 액션 게임입니다.
끝없이 이어지는 흑백 좌표평면 위에서 **매 웨이브 나타나는 보스**와 싸웁니다. 보스는 여러 함수 곡선을 쓰고,
처음엔 기본 함수 5종뿐이며 **미분·부정적분·극한으로 함수를 진화시켜** 새 무기를 얻습니다(결과는 수학적으로 맞는 함수).
TypeScript + Vite + HTML5 Canvas로 만들었고, 외부 이미지 없이 캐릭터·배경·이펙트를 모두 코드로 그립니다.

## 실행

```bash
npm install
npm run dev           # http://localhost:5173 에서 플레이
npm run build         # 타입 검사 + dist/ 빌드
npm run preview       # 빌드 결과 실행
npm run build:single  # 파일 하나짜리 게임 dist/fx-arena.html (내려받아 더블클릭으로 실행)
```

`build:single`은 JS·CSS를 HTML 안에 넣은 단일 파일을 만듭니다. 브라우저는 `file://`로 연 페이지에서
외부 모듈 스크립트를 막기 때문에, 서버 없이 파일만 공유·실행하려면 이 파일을 쓰세요.

## 화면

- **무한 좌표평면**: 배경 격자와 x·y축 눈금이 실제 월드 좌표와 같습니다(원점 = 시작 지점 근처, 1눈금 = 200px).
  카메라가 플레이어를 따라가면 눈금 숫자가 끊김 없이 이어지고, y축이 화면 밖이면 왼쪽 가장자리에 y 눈금이 표시됩니다.
  화면 왼쪽 위에 현재 위치 `P(x, y)`가 나옵니다. 지형은 시드에 따라 청크 단위로 무한히 생성됩니다.
- **흑백 테마**: 검은 바탕에 흰 선. 무기는 색 대신 곡선 모양으로 구분합니다.
  - 내 공격: 꽉 찬 흰 발광 곡선 / 적 공격: 속이 빈 이중선 / 적 예고선: 회색 점선
  - 적 종류는 머리 모양으로 구분: 근접형 ● · 일차함수 사수 ■ · 사인 술사 ◆ · 포물선 투척병 ▲ · 보스 왕관+f
  - 화면 밖의 적은 가장자리 화살표와 거리(눈금 단위)로 표시됩니다.

## 함수 진화와 인벤토리 (21종)

처음에는 **기본 함수 5종**(일차 · 절댓값 · 지수 · 탄젠트 · 원)만 가지고 시작합니다. `E`로 인벤토리를 열면
**진화 작업대**에서 보유한 함수에 **미분 d/dx · 부정적분 ∫dx · 극한 lim**을 적용해 새 함수를 얻습니다(원래 함수는 그대로 남습니다).
결과는 수학적으로 맞는 함수이고, 작업대에 수식과 결과 곡선 모양이 미리 보입니다. 진화에는 **진화 포인트(EP)**가 듭니다:
미분·적분 1, 극한 2. 시작 EP 3, **보스를 처치할 때마다 +1**. 얻은 함수는 핫바 5칸(숫자 키 1~5)에 꽂아 씁니다
(카드를 고른 뒤 슬롯을 누르거나 끌어다 놓기. 이미 다른 칸에 있으면 맞바뀌고, 교체하면 대기시간이 새 무기 기준으로 다시 시작).

**기본 함수인 이유**: 원은 함수가 아니라 도형이라 도함수·적분이 없고, eˣ는 미분·적분해도 자기 자신이라 다른 함수로 만들 수 없습니다.
일차·절댓값·탄젠트는 각자 계보(서로 이어지지 않는 묶음)의 뿌리입니다. 나머지 16종은 진화로만 얻습니다.

### 진화 지도

| 계보 | 관계 (→∫ 적분, ←d/dx 미분) |
| --- | --- |
| 다항 | 일차 `−x` →∫ 이차 `−x²` →∫ 삼차 `−x³` →∫ 사차 `−x⁴` (반대 방향이 미분. 일차의 미분은 상수라 끝) |
| 삼각 | sin →d cos →d −sin →d −cos →d sin, 적분은 반대 방향: ∫sin = −cos, ∫cos = sin, ∫(−sin) = cos, ∫(−cos) = −sin |
| 로그 | `x ln x − x` ⇄ `ln x` ⇄ `1/x`  ((x ln x − x)′ = ln x, (ln x)′ = 1/x) |
| 탄젠트 | `sec²x` ⇄ `tan x` ⇄ `−ln|cos x|`  ((tan x)′ = sec²x, ∫tan x = −ln|cos x|) |
| 절댓값 | `sgn x` ⇄ `|x|` ⇄ `x|x|/2`  ((|x|)′ = sgn x, ∫|x| = x|x|/2) |
| 지수 | (eˣ)′ = eˣ, ∫eˣ = eˣ: 자기 자신이라 진화 없음 |
| **극한** | 일차 → `e⁻ˣ` (lim(1 − x/n)ⁿ), 이차 → `cos x`, 삼차 → `sin x`, 사차 → `ln x` (테일러 급수: −x², −x³, −x⁴가 각각 n=2, 3, 4 항), 절댓값 → 우물 (lim\|x\|ⁿ) |

다항함수 계보는 모양이 위로 볼록해야 바닥에 덜 걸리므로 부호를 −로 잡았습니다(부호만 다른 같은 계보).
도함수·적분 간선은 수치 미분으로, 극한 간선은 급수 부분합의 수렴으로 단위 테스트가 검증합니다.

### 함수 무기 목록

| 함수 | 모양 | 얻는 법 |
| --- | --- | --- |
| 일차 `y = −x` | 직선 (피해 12→8, 대기 0.17→0.24s, 사거리 980→720으로 너프) | 기본 |
| 절댓값 `y = \|x\|` | 한가운데 꼭짓점의 대칭 V, 두꺼운 판정·강한 넉백 | 기본 |
| 지수 `y = eˣ − 1` | 완만하다 끝에서 급상승, 고피해 | 기본 |
| 탄젠트 `y = tan x` | 양 끝이 수직에 가까운 Z자, 넓은 쓸기 | 기본 |
| 원 `x² + y² = 1` | **온전한 원**: 총구와 커서를 지름으로 한 바퀴(매개변수 곡선) | 기본 |
| 이차 `−x²` / 삼차 `−x³` / 사차 `−x⁴` | 포물선 아치 / 완만한 S자 / 네모진 아치 | 일차에서 ∫ 연쇄 |
| 감쇠 `e⁻ˣ` / 코사인 / 사인 / 로그 `ln x` / 극한 우물 | 점근선으로 수렴 / 매달린 파동 / 파동 / 솟은 뒤 수평 / 직사각형 우물 | 극한 |
| −sin / −cos / 유리 `1/x` / `x ln x − x` / `sec²x` / `−ln\|cos x\|` / 부호 `sgn x` / `x\|x\|/2` | 반대 위상 파동 / 내리꽂기 / 비대칭 우물 / 깊은 우물 / 매끈한 U / 한 칸 계단 / 넓은 S자 | 미분·적분 |

### 조준: 곡선의 끝점이 커서에 닿는다

- 곡선은 **끝점(원은 총구에서 가장 먼 점)이 커서 위에 오도록** 방향을 돌리고 **크기를 줄입니다.**
  커서가 사거리 안이면 곡선이 정확히 커서까지만 뻗고(모양은 그대로 축소), 사거리를 넘으면 사거리까지 전체 길이로 뻗습니다.
  가까워도 20% 밑으로는 줄이지 않습니다(`REACH_MIN_SCALE`). 미리보기(점선)가 보여 주는 대로 날아갑니다.
- 카메라는 플레이어가 화면 가운데 데드존(±260px)을 벗어날 때만 움직여서, 이동 중에도 커서가 가리키는 월드 위치가 잘 흔들리지 않습니다.

- 대기시간은 슬롯마다 따로 돌기 때문에 번갈아 쏘면 공격 빈도를 높일 수 있습니다(무기 사이 최소 간격 0.14s).
- 곡선은 적을 관통하지만 한 번의 발사로 같은 적을 두 번 때리지 않습니다.
- **함수 상쇄**: 내 곡선은 적 탄환을 지우고, 뻗어 오는 적 곡선의 머리에 닿으면 그 곡선을 끊습니다.
- 밸런스는 자동 플레이 봇(조준 각도와 슬롯을 미리보기 경로로 고르는 봇)으로 조정했습니다.

## 보스

**모든 웨이브는 보스 한 마리뿐입니다**(잡몹 웨이브 없음). 보스를 처치하면 체력 30과 **진화 포인트 1**을 얻고 잠시 뒤 다음 보스가 나옵니다.
웨이브가 오를수록 체력이 조금씩(웨이브당 +13%) 늘고 피해가 약간 늘어납니다.

**함수의 군주**는 바닥만 밟고 발판은 통과하는 거인이며, 체력 60%·30%에서 단계가 오르고 단계마다 패턴이 늘어납니다.
공격은 모두 함수 곡선이고, 시전하는 동안 곡선의 경로가 점선(예고선)으로 먼저 보입니다. 예고선과 실제 경로는 같습니다.

- 1단계: 사인파 삼연발, 포물선 폭격, 절댓값 낙하(`y = −|x|` Λ가 플레이어 위로 내리꽂힘)
- 2단계: + 일차함수 부채꼴, 지수 올려치기(발판 위로 피한 플레이어를 노림)
- 3단계: + 방사형 직선 8방향, 탄젠트 쓸기

보스는 크게 너프되어 있습니다: 체력 2200→780, 이동 120→92, 몸통 피해 15→7, 공격 간격 2.0/1.6/1.25s → 3.2/2.7/2.3s,
예고 시간 0.85/0.7/0.6s → 1.25/1.1/1.0s, 곡선 피해·속도 약 40%·30% 감소, 부하 소환 삭제.
(근접형·사수·사인 술사·포물선 투척병 코드는 남아 있지만 웨이브에서는 나오지 않습니다. 디버그 `__fx.spawn()`으로 불러낼 수 있습니다.)
적의 함수 곡선도 플레이어 무기와 같은 곡선 생성기를 쓰므로 예고선과 실제 공격 경로가 같습니다.

## 함수 공격의 구현 방식

1. 정규화 매개변수 `t ∈ [0, 1]`로 정의역을 훑어 로컬 곡선을 만듭니다.
   `lx = L·t`, `ly = A·g(t)`, `g(t) = (f(x(t)) − f(x₀)) / max|f − f(x₀)|`
   (시작점을 원점=총구로 평행 이동, `L`=사거리, `A`=조준축에서 벗어나는 최대 높이)
2. 총구→커서 방향을 기준으로(곡선의 끝점이 그 방향 위에 오도록 돌려서) 로컬 x축, 그에 수직인 방향을 로컬 +y(수학적 위)로 삼아 월드 좌표로 회전·이동하고, 커서 거리에 맞춰 크기를 줄입니다.
   화면 좌표는 y가 아래로 커지므로 오른쪽 조준 시 +y = 화면 위쪽이 되도록 변환합니다.
   왼쪽을 조준하면 캐릭터가 뒤돌아보듯 그래프를 좌우 반전합니다(`COMBAT.mirrorWhenAimingLeft`, `false`면 순수 회전).
3. 곡선 길이 기준 4px 간격으로 다시 나눈 선분마다 지형과의 교차를 검사해 **처음 닿은 지점에서 자릅니다.**
4. 발사 순간의 경로를 저장하고, 머리가 진행 속도만큼 앞부분부터 드러납니다 → 잠시 유지 → 꼬리부터 걷히며 사라짐 → 판정 없는 희미한 잔상.
5. 매 스텝 **현재 보이는 구간 [꼬리, 머리]의 모든 선분**과 피격 상자 사이의 정확한 거리를 곡선 두께(반경)와 비교하므로, 한 스텝에 머리가 멀리 나아가도 판정이 누락되지 않습니다.
6. 조준 미리보기(점선)와 실제 발사는 같은 함수 `computeAttackPath()`를, 적 예고선과 적 공격은 `computeEnemyCurve()`를 씁니다.

## 새 함수 무기 추가하기

1. `src/config.ts`의 `WEAPON_TUNING`에 수치를 추가합니다.
2. `src/weapons/functions.ts`에서 등록합니다(등록 순서 = 인벤토리 카탈로그 순서).
   `starter: true`면 처음부터 보유, 아니면 다른 함수의 `evolves`(d/int/lim 간선: 결과 id·수식, 극한은 부분합 `series`)로 연결해 진화로 얻게 합니다.
   함수 그래프가 아닌 도형은 `trace`(매개변수 곡선)로 정의합니다(원 참고). 간선의 수학은 `tests/evolution.test.ts`가 검증합니다.

```ts
registerWeapon({
  id: 'cubic',
  name: '삼차함수',
  shape: 'S자',
  formula: 'y = x³',
  role: '…',
  color: '#ffffff',
  domain: [-1, 1],
  fn: (x) => x ** 3,
  tuning: WEAPON_TUNING.cubic,
});
```

미리보기·발사·충돌·HUD 슬롯과 아이콘·인벤토리 카드는 자동으로 따라옵니다. 적이 쓸 곡선은 `src/weapons/enemyPatterns.ts`에 같은 형태로 추가합니다.

## 밸런스 조정

`src/config.ts` 한 파일에서 조정합니다.

- `WEAPON_TUNING`: 플레이어 함수의 피해량, 진행 속도, 유지/사라짐 시간, 사거리(`range`), 곡률/높이(`amplitude`), 재사용 대기시간, 판정 두께, 넉백
- `ENEMY_PATTERN_TUNING`: 적·보스 곡선의 같은 항목
- `EVOLUTION`, `LOADOUT`, `REACH_MIN_SCALE`: 진화 포인트(시작·보스 보상·연산 비용), 핫바 슬롯 수·시작 장비, 커서 거리에 맞춘 최소 축소 비율
- `ENEMIES`, `WAVES`: 적 능력치, 보스 단계·체력·공격 간격, 웨이브 증가 곡선
- `TERRAIN`, `CAMERA`(데드존), `KEYS`: 지형 청크·좌표평면 원점과 눈금, 카메라, 조작 키

## 테스트

```bash
npm test             # 단위·시뮬레이션 테스트(Vitest)
npm run test:e2e     # 실제 브라우저에서 키보드·마우스 입력으로 검증(Playwright)
```

E2E를 처음 실행할 때 브라우저가 없다면 `npx playwright install chromium`을 먼저 실행하세요.
이미 설치된 Chromium을 쓰려면 `CHROMIUM_PATH=/경로/chrome npm run test:e2e`.
단일 파일 빌드를 검사하려면 `npm run build:single && E2E_URL=file://$PWD/dist/fx-arena.html node scripts/e2e.mjs`.

- 단위 테스트: 21종 곡선 모양(원은 닫힌 도형), 진화 그래프의 수학적 정합성(미분·적분은 수치 미분, 극한은 급수 수렴)·도달 가능성·기본 함수 조건, 보유·진화·장착 규칙, 커서에 곡선 끝점이 닿는지(모든 무기×거리에서 적 명중), 360° 회전, 좌우 반전, 지형 절단, 미리보기=발사 경로, 관통·중복 피해 방지·두께 경계·큰 스텝 누락 방지,
  프레임 속도 독립성, Space 점프·숙이기·턱 아래 일어서기 불가, 무한 지형(시드 재현성·청크 경계·좌우 끝없는 바닥),
  여러 시드×41청크 내비게이션 연결성, 카메라 데드존, 적 곡선(예고선=발사 경로·1회 피해·포물선 착지점·상쇄), 보스(패턴·단계·처치),
  스폰 제약, 보스 전용 웨이브, 그리고 봇이 실제 시스템 전체를 플레이하는 소크 테스트.
- E2E: 이동·Space 점프·숙이기, 이동과 독립적인 조준, 8종×8방향 미리보기=실제 경로, 지형 충돌, 슬롯 교체(1~5/휠), 인벤토리 열기·진화 작업대(∫·lim 진화, 자기 자신·EP 부족 처리)·장착·닫기,
  커서를 적에게 올리고 클릭하면 맞는지(21종),

## Codex CLI와 Claude Code CLI 함께 사용하기

두 CLI는 같은 로컬 저장소와 이 Mac의 GitHub 인증을 사용할 수 있습니다.
공통 작업 지침은 `AGENTS.md`에 있으며, `CLAUDE.md`가 이를 가져옵니다.
이미 열려 있는 세션에는 두 파일을 읽도록 요청하거나 프로젝트 폴더에서 새 세션을 시작하세요.

```bash
cd /Users/nadohyeon/project
codex
```

Claude Code를 사용할 때는 같은 폴더에서 `claude`를 실행합니다.
같은 폴더에서는 한 도구의 작업이 끝난 뒤 다른 도구에 이어서 맡기세요.
동시에 수정하려면 별도 Git worktree와 별도 브랜치를 사용합니다.
코드와 Git 이력은 공유하지만 두 도구의 대화 이력은 별개입니다.

GitHub 반영까지 원하면 어느 CLI에든 다음과 같이 요청할 수 있습니다.

> 이 기능을 구현하고 검증한 뒤, 이번 작업의 변경 사항만 커밋하고 현재 브랜치에 push해줘.

파일을 저장하거나 커밋하는 것만으로 GitHub에 업로드되지는 않습니다.
push는 `nxodh/project`의 현재 작업 브랜치를 업데이트하며, `main` 반영은 별도의 PR 병합으로 진행합니다.
Claude 클라우드에서 이어서 작업할 때도 GitHub의 최신 브랜치를 가져와야 합니다.

```bash
git status --short --branch
git branch -vv
git remote -v
```

위 명령으로 현재 변경 사항, 브랜치의 추적 대상, 원격 저장소를 확인할 수 있습니다.
인증과 실행 승인은 각 CLI의 설정을 따릅니다.
